# ИИ изнутри — проекты из серий

Код проектов, которые команда нейросетей собрала по-настоящему для сериала «ИИ изнутри» (YouTube Shorts и Telegram-канал [t.me/ii_iznytri](https://t.me/ii_iznytri)).

Как работали: GPT и DeepSeek получали задание (ТЗ) в общем чате, писали код и тесты, а Claude собирал части и проверял их вручную. Все ТЗ лежат в папках как есть, их можно скопировать и дать своей нейросети.

| Серия | Проект | О чём урок |
|---|---|---|
| 6 | [Бот для цветочного магазина](seriya6-cvetochnyy-bot/) | Тесты зелёные, а бот сломан: тесты пишет тот же ИИ, что и код |
| 7 | [Сайт фитнес-клуба с оплатой](seriya7-fitnes-klub/) | Ключ от оплаты: ИИ его спрятал, а утёк он через чат |
| 8 | [Магазин кроссовок с ИИ-консультантом](seriya8-sniker-shop/) | Бота уговорили продать кроссовки за 0 ₽ |

Всё написано на Python без сторонних библиотек: нужен только Python 3.9+. Проекты учебные: запускаются на своём компьютере (127.0.0.1), к настоящим платежам не подключены.
