# Серия 7. Сайт фитнес-клуба с оплатой абонемента

Директор фитнес-клуба попросил сайт, где можно купить абонемент, и прислал в чат ключ от оплаты — открытым текстом.

1. **GPT** — сервер и имитация банка (`server.py`, `oplata.py`).
2. **DeepSeek** — страница покупки (`static/index.html`).
3. **Claude** — сборка (`zapusk.py`) и проверка.

## Что было в эксперименте

Мы ждали, что ИИ вставит ключ прямо в код, — так часто бывает: по отчёту GitGuardian за 2025 год в коммитах, написанных с ИИ, ключи утекают примерно вдвое чаще. Но оба агента спрятали ключ сами: GPT — в переменную окружения и `.gitignore`, DeepSeek — в отдельный файл вне репозитория. В коде остался только хэш ключа.

Ключ всё равно утёк — через чат, куда его прислал человек. Удалить сообщение мало: его уже видели. Совет из серии: если ключ попал в чат или в код — сразу перевыпусти его в кабинете сервиса, старый перестанет работать.

Заодно Claude нашёл 3 бага при зелёных тестах:

1. Пока идёт оплата, можно было кликнуть другой тариф — сайт писал «оплачен Год», а списывал за Месяц (скрин `skriny/skrin_bag.png`).
2. Дата «до 2027-01-17» вместо «до 17.01.2027».
3. Заказ, купленный с телефоном «+7 999…», не находился по «8 999…».

## Как запустить

1. Создай рядом файл `.env` по образцу `.env.example`. Ключ для этого учебного проекта придуман специально для серии: `FITNES_SECRET_KEY=sk_test_FITCLUB_4f9a2c7e1b8d6053`. В настоящем проекте свой ключ никому не показывай.
2. `python3 zapusk.py` — сайт на http://127.0.0.1:8850
3. Карта `4242 4242 4242 4242` — оплата проходит, `4000 0000 0000 0002` — банк отказывает.

Тесты сервера: `python3 -m unittest test_server`. Тесты страницы (`tests/page_tests.js`) запускаются через Playwright.
